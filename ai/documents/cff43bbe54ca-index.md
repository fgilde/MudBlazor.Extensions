# Services Overview

MudBlazor.Extensions provides additional services for enhanced functionality.

## Available Services

- **[Speech Recognition](https://github.com/fgilde/MudBlazor.Extensions/blob/6117a6f4c245736610c1e6a9a0ca320fea66c9c3/docs/services/speech-recognition.md)** - Browser speech recognition API

## Service Registration

Services are automatically registered when you use:

```csharp
builder.Services.AddMudServicesWithExtensions();
```
