# Services Overview

MudBlazor.Extensions provides additional services for enhanced functionality.

## Available Services

- **[Speech Recognition](https://github.com/fgilde/MudBlazor.Extensions/blob/5392d730d478adeeb353c4541ddbde4a6d7b64a5/docs/services/speech-recognition.md)** - Browser speech recognition API

## Service Registration

Services are automatically registered when you use:

```csharp
builder.Services.AddMudServicesWithExtensions();
```
