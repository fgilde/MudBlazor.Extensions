# Services Overview

MudBlazor.Extensions provides additional services for enhanced functionality.

## Available Services

- **[Speech Recognition](https://github.com/fgilde/MudBlazor.Extensions/blob/8049d73067d2ecf87f61856b623bc55f608ea607/docs/services/speech-recognition.md)** - Browser speech recognition API

## Service Registration

Services are automatically registered when you use:

```csharp
builder.Services.AddMudServicesWithExtensions();
```
