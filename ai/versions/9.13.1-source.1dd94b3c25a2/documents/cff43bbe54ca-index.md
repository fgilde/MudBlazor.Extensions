# Services Overview

MudBlazor.Extensions provides additional services for enhanced functionality.

## Available Services

- **[Speech Recognition](https://github.com/fgilde/MudBlazor.Extensions/blob/1dd94b3c25a20fe821e24e87fb47b22656c66ae3/docs/services/speech-recognition.md)** - Browser speech recognition API

## Service Registration

Services are automatically registered when you use:

```csharp
builder.Services.AddMudServicesWithExtensions();
```
