# Services Overview

MudBlazor.Extensions provides additional services for enhanced functionality.

## Available Services

- **[Speech Recognition](https://github.com/fgilde/MudBlazor.Extensions/blob/fd8e30adddf8877e69e672278398a2b95d86989e/docs/services/speech-recognition.md)** - Browser speech recognition API

## Service Registration

Services are automatically registered when you use:

```csharp
builder.Services.AddMudServicesWithExtensions();
```
